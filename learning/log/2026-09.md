- data mining: process that uses a variety of data processing tools in order to discover patterns and relationships in data to help build useful models and make decisions

- data analytics: describes any use of statistical analysis to drive business decisions from data

- big data: datasets so large and complex that it becomes difficult for traditional methods to capture, store, visualize, and analyze them

---

**Data mining process**
1st phase: business understanding - business problem should be defined. Best to have a specific problem before you start

2nd phase: data understanding - central to the entire data mining process.

3rd phase: data preparation - time consuming part. Within this, investigate missing values. Correct wrong or inconsistent values, reconclie data definitions, emerge data sources. Clean, adjust, derived variables is the most important

^team effort. Team should decide how much effort is reasonable to make the dataset as complete and reliable as possible

4th phase: modeling - explore this space, develop models. If number of vars is too large, perliminary analysis is necessary to narrow down the candidate predictors

5th phase: evaluation - candidate models are tested against the test data and various criteria are used to judge the model. If the final model gains insight into the business problem, it's time for deployment

6th phase: deployment -

CRISP: cross industry standard product - iterative and interconnected process

**partitioning data**

Initial data has 2 parts: 

1st part: training data - build the model on training data - if the model has used this data, the data is seen by the model
2nd part: validation data - if the model that you built in training ^ doesn't need to be tweaked on validation data, use the validation dataset to evaluate the performance of the model. Unseen 

- if the model built on training data needs to be tweaked on validation data, it is now seen, then a third dataset is necessary to evaluate the performance of the model. People call this 3rd data set testing data. 

If a model has already seen a dataset, you cannot use this dataset to eval perfomance on the models (one has an advantage over another that hasn't seen the data yet)
