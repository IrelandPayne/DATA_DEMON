# Relational database basics

Notes from DataCamp — Associate Data Analyst in SQL, intro section.

- SQL (Structured Query Language) is the most widely used language for working with data stored in databases.
- Database: stores data reliably, retrieves information efficiently, manipulates data systematically.
- The most popular type is a relational database — tables hold a specific entity, a row represents a single entity, and a column represents a specific attribute/property of the entity (only 1 value per row).
