# 04 · Math & Statistics

The statistics that actually show up in analysis and ML, not the full theory course.

## Covers

- Descriptive statistics, distributions
- Hypothesis testing, confidence intervals
- Probability basics, Bayes' theorem
- Linear algebra and calculus only as far as ML needs them

## Resources (free)

- [Seeing Theory](https://seeing-theory.brown.edu/)
- [StatQuest (YouTube)](https://www.youtube.com/@statquest)
- [Khan Academy: Statistics & Probability](https://www.khanacademy.org/math/statistics-probability)

## Milestones

- [ ] Run and correctly interpret a hypothesis test, including what it doesn't prove
- [ ] Explain a confidence interval without saying "there's a 95% chance the true value is in here"
- [ ] Spot when a distribution assumption is wrong for the data
- [ ] Use Bayes' theorem on a real, non-textbook example
