# 06 · Machine Learning

Core algorithms, scikit-learn, and how to tell if a model is actually good.

## Covers

- Regression, classification, clustering
- Train/test splits, cross-validation, overfitting
- Model evaluation metrics, picked to match the problem, not by default

## Milestones

- [ ] Build a full pipeline: split, train, evaluate, without data leakage
- [ ] Pick an evaluation metric that fits the problem and justify it (not default accuracy)
- [ ] Diagnose overfitting vs. underfitting from a learning curve
- [ ] Explain a model's predictions, not just its score
