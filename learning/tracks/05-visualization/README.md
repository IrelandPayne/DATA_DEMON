# 05 · Visualization

Telling a straight story with a chart, not a cluttered one.

## Covers

- matplotlib and seaborn fundamentals
- Chart choice: when a chart type is honest vs. misleading
- Power BI: data modeling, DAX basics, report/dashboard building
- Dashboards: light intro (Streamlit or similar)

## Resources (free)

- [MLU-Explain](https://mlu-explain.github.io/)
- [Data Visualization Society resources](https://www.datavisualizationsociety.org/resources)
- [seaborn docs / tutorial](https://seaborn.pydata.org/tutorial.html)
- [Microsoft Learn: Power BI](https://learn.microsoft.com/en-us/training/powerplatform/power-bi) (Power BI Desktop is free)

## Milestones

- [ ] Build a chart that would mislead if the axis/scale choice were different, then fix it
- [ ] Build a Power BI report with at least one calculated DAX measure
- [ ] Build a small interactive dashboard (Streamlit or Power BI)
- [ ] Get feedback from someone outside the field on whether a chart reads clearly in 5 seconds
