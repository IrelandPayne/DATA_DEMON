# 00 · Excel

Spreadsheet fluency: still the first tool most analysts touch on the job, and often the fastest way to hand someone an answer.

## Covers

- Formulas: VLOOKUP/XLOOKUP, INDEX/MATCH, SUMIFS/COUNTIFS, nested logic
- Pivot tables and pivot charts
- Data cleaning in-sheet: text-to-columns, removing duplicates, data validation
- Basic modeling: what-if analysis, goal seek, simple forecasting
- Conditional formatting and clean, readable spreadsheet layout

## Resources (free)

- [Awesome Excel](https://github.com/NajiElKotob/Awesome-Excel) — curated list, main source for this track
- [Exceljet](https://exceljet.net/) — formula reference and examples
