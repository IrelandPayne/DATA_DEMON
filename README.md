# DATA_DEMON

A data analytics / data science portfolio and study log, covering Python, SQL, statistics, visualization, machine learning, and deep learning. Built July–August 2026 using free resources.

## Project Description

This repo has two parts:

- **`projects/`** — finished, standalone data analysis projects. Each one is documented with its method, results, and limitations. This is the fastest way to see actual work rather than a list of claimed skills.
- **`learning/`** — the study log behind it: eight tracks, each with its own notes and exercises, plus a dated log of what was covered and when.

## Skills covered

- Python for data analysis (pandas, NumPy, Jupyter)
- SQL (querying, joins, schema design, query performance)
- Statistics (descriptive stats, hypothesis testing, probability)
- Visualization and BI (matplotlib, seaborn, Power BI)
- Machine learning (regression, classification, clustering, scikit-learn)
- Big data (Spark basics, cloud data warehouse concepts)
- Deep learning (neural nets, PyTorch)
